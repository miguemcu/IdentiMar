# IdentiMar

Aplicación móvil para el registro e identificación de batoideos en el Urabá Antioqueño.

> Proyecto Integrador I — Ingeniería de Sistemas
> Universidad de Antioquia

## 📱 Descripción

**IdentiMar** es una aplicación móvil orientada al registro y apoyo en la identificación de batoideos (rayas) observados en el Urabá Antioqueño.

La aplicación busca facilitar el registro de observaciones mediante fotografías y datos básicos de campo, proporcionando una identificación sugerida y permitiendo posteriormente la validación de los registros por usuarios con perfil de experto.

El proyecto se desarrolla en el marco de **Proyecto Integrador I** de Ingeniería de Sistemas de la Universidad de Antioquia, en colaboración con **INVEMAR**.

## 🎯 Objetivo

Desarrollar una herramienta móvil que facilite la recopilación y gestión de registros de batoideos, apoyando los procesos de identificación y validación de observaciones realizadas en campo.

## ✨ Funcionalidades principales

* Registro de nuevas observaciones.
* Captura o selección de fotografías de batoideos.
* Registro de información básica de la observación.
* Consulta de una identificación sugerida.
* Visualización de registros.
* Consulta de información relacionada con las especies.
* Gestión del perfil del usuario.
* Proceso de certificación como usuario experto.
* Validación de identificaciones por parte de usuarios expertos.

## 🛠️ Tecnologías

* **React Native**
* **Expo**
* **TypeScript**
* **Git / GitHub**

La aplicación móvil consume servicios proporcionados por la infraestructura del proyecto para el procesamiento y gestión de las observaciones.

## 🎨 Diseño

La interfaz utiliza el sistema visual Bentos Costero, diseñado para proporcionar una experiencia sencilla, clara y adecuada para el uso en dispositivos móviles y contextos de campo. Su identidad cromática combina la claridad de las aguas someras y los fondos arenosos, utilizando un azul océano claro (`#0284C7`) para las acciones principales, un ocre pálido (`#FCD34D`) que evoca la arena costera para destacar elementos secundarios, y una base limpia sobre grises marfil (`#F4F6F8`) y textos en pizarra (`#1E293B`) que garantizan una lectura óptima.

Principios principales:

* Interfaz completamente en español.
* Navegación sencilla e intuitiva.
* Elementos táctiles fácilmente identificables.
* Buena legibilidad en exteriores.
* Reducción de terminología técnica para usuarios generales.
